- Commands: `flutter pub get` · `flutter analyze` (infos are fatal) · `flutter test` · `flutter run --dart-define=API_BASE=http://10.0.2.2:8080` (Android emulator; iOS simulator can use the default `__API_URL__`).
- Material comes from `package:material_ui/material_ui.dart` (not `package:flutter/material.dart`) — never mix the two imports.
- Layout: `lib/app` (app, router, theme + `AppSpacing` ThemeExtension) · `lib/core` (config, Dio + auth interceptor) · `lib/features/<f>/{data,domain,presentation}`.
- State: plain Riverpod 3 providers/`AsyncNotifier` (no codegen yet); every screen handles loading, error (with retry) and empty.
- API shapes follow `contracts/openapi.yaml` (`/v1/notes`); hand-written DTOs live only in `features/*/domain` until a generated client lands in `lib/api/gen/` (never edit generated code).
- Theme tokens only (`Theme.of(context)`, `context.spacing`); no hard-coded colors; touch targets ≥ 48dp; tooltips on icon buttons.
- Platform folders (android/, ios/) are generated by `flutter create .`; commit them and `pubspec.lock` after the first green verify.
