- Commands: `pnpm dev` · `pnpm dev:worker` (build + `wrangler dev`, the closest thing to production) · `pnpm run typecheck` · `pnpm run lint` · `pnpm run test` (offline) · `pnpm run build` (`nuxt generate`, output in `.output/public`).
- Nuxt 4 static site, prerendered at build time (`ssr: true` + `nuxt generate`; no runtime server, no API, no Nitro routes) + Nuxt UI/Tailwind v4. This is the one place a site differs from the app templates, which run `ssr: false`: a site needs real HTML for search engines and link previews.
- Layout: `app/data/site.ts` holds the site name, tagline, nav and the text of every page (`site.pages.*`), so replacing the sample copy is one file; each page is a file in `app/pages/` and sets `useSeoMeta({ title, description })`. A new page is a new file plus a `site.nav` entry (a test checks they match). Keep new copy in `site.ts` too.
- Deploy: one Cloudflare Worker with static assets only (`wrangler.jsonc`, no code per request). `wrangler deploy --env staging` is the preview; `--env production` needs a human. Set `NUXT_PUBLIC_SITE_URL` to the real origin at build time (sitemap URLs) and update `public/robots.txt`.
- Ship only what the site uses: Nuxt UI components are auto-imported, so only the ones a page renders end up in the bundle (use them by name, don't register the library globally); `ui.experimental.componentDetection` is on, so CSS is generated only for components a page renders; a component chosen at runtime (`<component :is>`) must be listed there. Icons are `i-lucide-*` from the local `@iconify-json/lucide`, and `icon.clientBundle.scan` bundles just the ones in use. Don't turn `icon.fallbackToApi` back on (it makes the browser call a third-party API).
- Copy comes from the user's brief (the intent doc when there is one); never invent metrics, customer logos, testimonials or prices. `site.contactEmail` ships as `hello@example.com` and must be replaced before deploy. There is no form backend: the contact page is a `mailto:` link.
- Links between pages are crawled at build time and a broken one fails `pnpm run build`. Add pages that nothing links to under `nitro.prerender.routes` in `nuxt.config.ts`.
- Need a blog, editors writing Markdown, or media on R2? That is the `site-marketing` template (Nuxt Content).
