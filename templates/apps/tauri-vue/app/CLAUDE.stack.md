- Tauri v2 desktop app: Vite + Vue 3 + Vue Router (hash history) SPA with Nuxt UI via its Vite plugin (`@nuxt/ui/vite`) + Tailwind v4; Rust commands are the BFF. `pnpm dev` = `tauri dev`; `pnpm typecheck|lint|test|build` cover the frontend only; Rust, run from `src-tauri/` as two separate commands (PowerShell 5.1 has no `&&`): `cargo clippy --all-targets -- -D warnings`, then `cargo test`.
- The UI talks to Rust only through the typed wrappers in `src/lib/tauri.ts` (never `fetch()` to remote APIs). Commands in `src-tauri/src/commands/` stay thin; logic lives in `services/`; every error is the one serializable `AppError` (`error.rs`).
- New command = fn in `commands/` + register in `lib.rs` `generate_handler!` + add to `COMMANDS` in `build.rs` + `allow-<command>` in `capabilities/default.json` + wrapper and test in `src/lib/`.
- Local data: SQLite (rusqlite, bundled) in the app data dir; add a new file in `src-tauri/migrations/` and append it to `MIGRATIONS` in `services/db.rs` (never edit a shipped migration).
- File-based routing (vue-router 5 built-in `vue-router/vite`, Nuxt-style): pages in `src/pages/` (`index.vue`, `[...path].vue` = not found), meta via `definePage()`. `src/typed-router.d.ts` is GENERATED (regenerated by `pnpm dev:web`/`build`/`test`) and committed: never hand-edit; typed route names make a wrong `name` fail `pnpm typecheck`.
- Explicit imports only (auto-imports are off in `vite.config.ts`): Vue APIs from `vue`, Nuxt UI components as `import UButton from '@nuxt/ui/components/Button.vue'`. Keep `server.port` = `devUrl` port and `frontendDist` = `../dist`; keep the CSP strict and capabilities least-privilege (no `fs:`/`shell:` grants); validate every command argument; don't edit `src-tauri/gen/`. Icons are bundled locally (`@iconify-json/lucide`), no CDN.
