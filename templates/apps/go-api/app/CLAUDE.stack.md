- Commands (in this dir): `go run ./cmd/server` (needs `DATABASE_URL`, see `.env.example`; `docker compose up -d postgres` from the repo root), `go generate ./...`, `go vet ./...`, `go tool golangci-lint run`, `go test -v ./...`. Tools (oapi-codegen, sqlc, goose, golangci-lint) are `go tool` deps: no global installs.
- Contract-first: edit `contracts/openapi.yaml` -> `go generate ./...` -> implement on `internal/<module>/handler.go`. New operations require auth unless the contract says `security: []` (then add them to `server.PublicOperations`). Breaking change = tier L.
- Never edit `internal/api/gen/`, `internal/db/sqlc/` or an applied migration; schema changes are new `migrations/NNNN_*.sql` (goose, append-only) + `internal/db/queries/*.sql`, then `go generate`.
- Layers: `handler.go` decodes + maps errors to RFC 9457 problem+json; `service.go` holds rules, audit lines and ownership (every query scoped by the signed-in user from `auth.PrincipalFrom(ctx)`: no IDOR); `repo.go` is sqlc only.
- Auth (`internal/auth`): web = opaque `session` cookie (HttpOnly, Secure, SameSite=Lax, sliding) via the edge proxy; unsafe cookie requests need `X-Requested-With: fetch` + an `ALLOWED_ORIGINS` Origin (CSRF). Native = opaque bearer (15m) + refresh token rotated on every use (reuse revokes the session; hard cap `REFRESH_ABSOLUTE_TTL`, 90d). 429s carry `Retry-After`. Passwords argon2id; tokens stored as SHA-256 only.
- Auth config (see `.env.example`): `APP_URL`, `API_PUBLIC_URL`, `ALLOWED_ORIGINS`, `TRUSTED_PROXIES`, `COOKIE_*`, `AUTH_PASSWORD`, `AUTH_REGISTRATION`, `MAGIC_LINK=off|log|smtp` + `SMTP_*`, `NATIVE_REDIRECT_URIS`, `OIDC_PROVIDERS` + `OIDC_<ID>_*`. `APP_ENV=production` refuses insecure values.
- Add an IdP: `OIDC_PROVIDERS=<id>` + `OIDC_<ID>_ISSUER/_CLIENT_ID/_CLIENT_SECRET` (no code); register callbacks `${APP_URL}/api/v1/auth/oidc/<id>/callback` (web) and `${API_PUBLIC_URL}/v1/auth/oidc/<id>/callback` (native). New mailer: implement `auth.Mailer`.
- Links: web magic link `${APP_URL}/auth/magic?token=` (SPA posts it to `/v1/auth/magic-link/verify`); native `<first NATIVE_REDIRECT_URIS>/magic?token=` and OIDC: `/start?client=native&codeChallenge=<S256>&codeChallengeMethod=S256` -> `<redirect>?code=` -> `/v1/auth/token` with `codeVerifier` (PKCE, RFC 8252); OIDC failures: web `${APP_URL}/login?error=<code>`, native `<redirect>?error=access_denied|server_error|invalid_request`.
- Never log tokens, codes, passwords, cookies or full emails (`auth.MaskEmail`); log paths, never query strings. Rate limits are in-memory per instance: also rate limit at the edge.
- DB tests skip without `DATABASE_URL`; run them against `docker compose up -d postgres`. `go test -race` needs cgo (a C toolchain), so it is not in the default verify.
