- Commands: `pnpm dev` (Vite, proxies `/api` to the Go API on :8080) · `pnpm dev:worker` (build + `wrangler dev`) · `pnpm typecheck` · `pnpm lint` · `pnpm test` · `pnpm build` · `pnpm gen:api` (regenerates `src/api/schema.d.ts` from `../contracts/openapi.yaml`; never hand-edit it).
- Vite + React + TypeScript static SPA, TanStack Router (code-defined routes in `src/router.tsx`) + TanStack Query, shadcn/ui + Tailwind v4 (add components with `pnpm dlx shadcn@latest add <name>`). One Cloudflare Worker (`worker/index.ts`, `wrangler.jsonc`) serves the SPA and passes `/api/*` through to the Go API at `ORIGIN_URL` with the `/api` prefix stripped. The Worker never contains business logic — that's the Go API.
- Auth: first-party session cookie, same-origin via the Worker. All calls go through `src/api/client.ts` (adds `X-Requested-With: fetch`); the UI renders only the methods from `GET /v1/auth/providers`. The guard is `beforeLoad` on the `app` route in `src/router.tsx` (401 from `/v1/auth/me` → `/login?redirect=…`); put signed-in pages under it.
- Set the API's allowed origins to the app origin (`http://localhost:5173` in dev, the deployed URL otherwise) and per-env `ORIGIN_URL` in `wrangler.jsonc` before the first deploy.
- Tests: vitest, offline — `worker/index.test.ts` calls the Worker with Requests and a stubbed `fetch`; `src/test/` renders the app against a stubbed API. Contract change: edit `contracts/openapi.yaml`, run `pnpm gen:api`, commit the result.
