- Commands: `pnpm dev` (SPA, proxies `/api` to the Go API on :8080) · `pnpm dev:worker` (build + `wrangler dev`) · `pnpm typecheck` · `pnpm lint` · `pnpm test` · `pnpm build` (`nuxt generate`) · `pnpm gen:api` (regenerates `app/api/schema.d.ts` from `../contracts/openapi.yaml`; never hand-edit it).
- Nuxt 4 static SPA (`ssr: false`, no server routes) + Nuxt UI/Tailwind v4, file routing in `app/pages/`. One Cloudflare Worker (`worker/index.ts`, `wrangler.jsonc`) serves the SPA and passes `/api/*` through to the Go API at `ORIGIN_URL` with the `/api` prefix stripped. The Worker never contains business logic — that's the Go API.
- Auth: first-party session cookie, same-origin via the Worker. All calls go through `app/api/client.ts` (adds `X-Requested-With: fetch`); the UI renders only the methods from `GET /v1/auth/providers`. `app/middleware/auth.global.ts` redirects 401 to `/login?redirect=…`; mark public pages with `definePageMeta({ public: true })`.
- Set the API's allowed origins to the app origin (`http://localhost:3000` in dev, the deployed URL otherwise) and per-env `ORIGIN_URL` in `wrangler.jsonc` before the first deploy.
- Tests: vitest, offline — `test/worker` calls the Worker with Requests and a stubbed `fetch`; `test/nuxt` runs pages/guard with a stubbed API. Contract change: edit `contracts/openapi.yaml`, run `pnpm gen:api`, commit the result.
